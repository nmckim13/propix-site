# Pro Pix — Real Estate Photography Website

Production site for [propix3d.com](https://propix3d.com).

## Stack
- Pure HTML/CSS/JS — no framework, no build step
- Deployed on Vercel
- Images served from `/public/images/`

## Deploy
Push to `main` → Vercel auto-deploys.
